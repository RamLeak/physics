# FIX: MatchMethod — баг с подсветкой

## Проблема

Сейчас когда пользователь только выбирает топик слева (один клик) — он сразу видит зелёный цвет на топике и/или на правильном описании справа. Это **спойлер** — нельзя «угадать», система показывает правильный ответ заранее.

Скрин: выбран "Система отсчёта (3 компонента)" слева — зелёный. Описание "Система отсчёта (СО) состоит..." справа — тоже зелёный. Ни одна пара ещё не подтверждена.

## Что должно быть (правильное поведение)

1. **Невыбранная карточка** (топик или описание) — фон `bg-slate-800`.
2. **Выбранный, но не спаренный топик** — фон `bg-blue-900` (синий, чтобы НЕ путать с зелёным финалом).
3. **Описание** до клика — всегда `bg-slate-800`. Никаких подсказок «правильное описание подсвечено».
4. **Спаренные пары** (после двух кликов):
   - Если правильно — обе карточки `bg-green-900`
   - Если неправильно — обе карточки `bg-red-900`
5. **Спаренная карточка нельзя выбрать заново** (disabled, opacity-60).

## Что делать

Открой `src/components/methods/MatchMethod.tsx`.

Найди функцию `colorFor` (или эквивалентный код, который определяет цвет фона карточки). Замени её логику на:

```typescript
// Цвет для топика (левая колонка)
const colorForTopic = (topicId: string): string => {
  const pair = pairs.find((p) => p.topicId === topicId);
  if (pair) return pair.correct ? "bg-green-900" : "bg-red-900";
  if (topicId === selectedTopic) return "bg-blue-900";
  return "bg-slate-800";
};

// Цвет для описания (правая колонка)
const colorForContent = (contentId: string): string => {
  const pair = pairs.find((p) => p.contentId === contentId);
  if (pair) return pair.correct ? "bg-green-900" : "bg-red-900";
  return "bg-slate-800";
};
```

Затем в JSX замени все вызовы `colorFor(...)` соответственно на:
- В блоке топиков (левая колонка) — `colorForTopic(t.id)`
- В блоке описаний (правая колонка) — `colorForContent(c.id)`

Также убедись что:
- Кнопки топиков с `disabled={isPaired(t.id)}` — должны иметь `opacity-60` через классы (`disabled:opacity-60`).
- Кнопки описаний — то же самое: `disabled={isPaired(c.id) || !selectedTopic}` (нельзя кликать если ничего не выбрано слева).
- При клике на описание без выбранного топика — ничего не происходит.

## Финальная проверка

Запусти `npm run build` — должно собраться чисто.

Сценарий теста:
1. Открой Match для любой карточки билета 1.
2. Никаких карточек не выбрано — все фоны `bg-slate-800` (тёмно-серые).
3. Кликни любой топик слева — он становится **синим** (`bg-blue-900`). Описания справа остаются тёмно-серыми.
4. Кликни описание справа — пара становится **зелёной** (если угадал) или **красной** (если нет). Если красная — посмотри, какой топик подсветился красным, какое описание — у тебя в голове отложится правильная связь.
5. Продолжай пока все 5 пар не сопоставлены.
